# 🧮 Science Track Math Calculator (`cubed-calcing`)

![Build](https://shields.io)
![Math](https://shields.io)

> **Because doing `7 * 8` in your head during a coding session is a high-risk sport.**

A sleek, zero-bloat web calculator built for instant arithmetic without opening a heavy spreadsheet or dealing with ads. 

👉 **[Try the Live Demo](https://samarthnarsipur.github.io/cubed-calcing/)**

---

## ✨ What It Does
* **Core Arithmetic:** Fast, reliable `+`, `-`, `*`, and `/` operations.
* **Panic Button (`C`):** Clears your mistakes instantly—no judgment if you hit it five times in a row.
* **Zero Bloat:** Built with pure HTML, CSS, and Vanilla JavaScript. No 500MB `node_modules` folder required.

---
